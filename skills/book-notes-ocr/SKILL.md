# Book Notes OCR（书页截图 → 读书笔记）

> ⚠️ **仅适用于 macOS**：依赖系统自带的 Swift 编译器与 Vision 框架（macOS 10.15+），零第三方依赖，可在新环境快速实现。非 macOS 环境请改用 tesseract（需另装 `chi_sim` 语言包）或云 OCR。

把一批书页截图批量识别为文本，再整理为结构清晰的读书笔记。固定流程：**先整洁目录 → 再 OCR → 再整理**。

## 工作流

### 1. 整理目录（保持根目录整洁）
- **通用工具留根目录**：OCR 脚本（`ocr_script.swift`）与说明文档（如 `OCR处理说明.md`）保留在根目录，供各书复用
- **每本书一个专属文件夹**：以书名命名，图片放其 `Images/` 子目录，该书读书笔记文档也放其中
- 结构示意：
  ```
  根目录/
  ├── ocr_script.swift          # 通用 OCR 脚本（各书复用，勿移入书文件夹）
  ├── OCR处理说明.md            # 通用说明
  └── 《书名》/                 # 图书专属
      ├── Images/               # 该书全部截图
      └── 《书名》读书笔记.md
  ```

### 2. OCR 识别（macOS 原生）
- 使用本技能自带脚本 [scripts/ocr_script.swift](./scripts/ocr_script.swift) 批量识别
- 运行：
  ```bash
  cd "书名文件夹所在目录"
  swift ocr_script.swift "《书名》/Images/"*.jpg > ocr_output.txt 2>&1
  ```
- 脚本要点：`VNRecognizeTextRequest` + `.accurate` + `zh-Hans`（简体中文）+ `usesLanguageCorrection`，并按 boundingBox 还原阅读顺序

### 3. 整理为读书笔记（核心）
- **剔除标题编号**：`12. 爱护自负的人` → `爱护自负的人`
- **保留加粗原句**：每章标题下第一句格言即原书加粗句，作为笔记副标题保留
- **写理解性总结**：言简意赅，一段话提炼核心，并**融合事业/职场参考**（军事原则 → 商业场景）
- **修正 OCR 错字**：结合上下文校正（如「敏少」→「缺少」）；异体字/手写需人工复核
- **按章节编号排序**：跳跃式选拍的页面按编号从小到大重排

### 4. 输出与校验
- 生成 `《书名》读书笔记.md`；既有文档不破坏（增量更新优先）
- 校验：`grep '^## '` 确认章节齐全、编号已剔除

## 红线
- ❌ 不删除稳定运行的脚本（`ocr_script.swift` 保留在根目录，不随单本书移入书文件夹）
- ❌ 不覆盖/破坏既有笔记文档（用追加或增量方式更新）
- ❌ 非 macOS 环境不硬跑 Vision 方案，先说明替代路径
