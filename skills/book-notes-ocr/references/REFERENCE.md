# 参考：方案选型、参数与常见坑

## 为什么用 Apple Vision（仅 macOS）

| 方案 | 评估 | 结论 |
|------|------|------|
| Tesseract | 默认仅 `eng`/`osd`/`snum`，无 `chi_sim`，需另装语言包 | 弃用 |
| Apple Vision（macOS 原生） | 内置高质量中文 OCR，Swift 系统自带，零第三方依赖 | ✅ 采用 |

## 关键参数

| 参数 | 值 | 作用 |
|------|-----|------|
| `recognitionLevel` | `.accurate` | 高精度（比 `.fast` 慢但准，适合书页正文） |
| `recognitionLanguages` | `["zh-Hans", "en-US"]` | 简体中文为主、英文为辅，支持中英混排 |
| `usesLanguageCorrection` | `true` | 结合上下文纠正同音/形近错字 |
| `minimumTextHeight` | `0.005` | 滤除水印/过小文字（约为图高 0.5%） |

## 排序逻辑（还原阅读顺序）

- Vision 文本框坐标为**左下角原点**的归一化坐标（0~1）
- 按 `boundingBox.midY` **降序**（上→下）
- 同一行（`|ΔmidY| ≤ 0.01`）内按 `minX` **升序**（左→右）

## 常见坑

1. **首次编译慢**：Swift 脚本首次运行需几秒编译，属正常现象
2. **输出过长**：批量识别时重定向到文件（`> ocr_output.txt`）再分段读取
3. **异体字/手写误识别**：如「餅究」类异体字，需结合上下文人工校正
4. **zsh 通配符**：路径含空格/中文时，建议用引号包裹目录再 glob（如 `"《书名》/Images/"*.jpg`）
5. **页面边缘装饰文字**（水印）可能被误识别，整理时过滤

## 批量命令

```bash
cd "书名文件夹所在目录"
swift ocr_script.swift "《书名》/Images/"*.jpg > ocr_output.txt 2>&1
```

4. **按编号排序**：跳跃式选拍的页面按章节编号重排
